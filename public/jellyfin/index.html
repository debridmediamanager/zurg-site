01 / The plugins

One for each account.
Install only what you use.

They do not need each other and they do not need the folder. A server with only a TorBox account installs one plugin and is done.

Real-Debrid

Your torrents as movies and shows. Real-Debrid quite often hands back a release wrapped in an archive without saying so, and this reads straight through it rather than handing your player something it cannot open.

AllDebrid

The same library from an AllDebrid account. A resync asks about twenty releases at a time, so keeping a large account up to date costs very little.

TorBox

Your TorBox library, streamed through your own server. A TorBox delivery link carries your API key inside it, so this never hands one to a player.

Usenet

Point it at a folder of NZB files. Nothing is fetched until you press play, and then only the pieces that part of the film needs. Nothing is ever written to disk.

02 / Which one

The folder, or
the plugins.

They solve the same problem for different setups. Nothing stops you running both, and plenty of people will.

Use the folder

When more than Jellyfin has to read your library. Plex, Emby, Infuse, a file manager, or an *arr stack that wants real paths. The folder is a normal drive and everything understands it.

Read about the folder →

Use the plugins

When Jellyfin is the only thing that reads your library and you would rather not run anything else. There is no mount to survive a reboot and no second service to keep alive.

03 / Honestly

The things they
will not do.

Written down here so you find out now rather than after an evening of setup.

Only Jellyfin sees it

The library lives inside Jellyfin. Nothing outside it can read those files, so an *arr stack or a second media server needs the folder instead.

Only stored archives

A release packed with compression, or one that is encrypted, is left out of the library rather than added as an item that opens and then fails.

Jellyfin 12 and up

They are built against Jellyfin 12. An older server cannot load them.

04 / Getting started

Three steps.
All of them inside Jellyfin.

1. Add the repository

Your repository URL is on your Debrid Media Manager account page, already filled in with your key. Paste it into Jellyfin under Dashboard, Plugins, Repositories.

Open your setup page →

2. Install what you use

The plugins appear in the Jellyfin catalog. Install the ones matching your accounts and restart the server.

3. Paste your account key

Open the plugin settings, add your account key and the address your players reach Jellyfin at, then run the sync. Your library appears.
