zurg+rex means running a Plex server on your phone. One app runs zurg and rex together. Sign in to Plex in the app and your library shows up in the Plex apps on every device at home. The app installs its engine after you sign in to GitHub inside it. Usenet needs 64-bit. Android setup

Docker

On a Linux host one command sets up everything and asks for your providers.

curl -fsSL https://raw.githubusercontent.com/debridmediamanager/zurg-site/main/public/install-docker.sh | bash

Or pull the image yourself. The password is a classic GitHub token with the read:packages and repo scopes.

docker login ghcr.io -u YOUR_GITHUB_USERNAME
docker pull ghcr.io/debridmediamanager/zurg:latest

Or install with one command

The script signs you in to GitHub and downloads the right build. Then it runs setup.

Linux and macOS
